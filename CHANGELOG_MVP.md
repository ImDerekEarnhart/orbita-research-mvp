# Orbita Research MVP changelog

## 0.1.0

- Combined Orbita Epistemic Runtime v1.5 with the Discovery Kit engine.
- Added case, upload, profile, plan, approval, run, and report workflow.
- Added blank-goal Open Discovery for parsed tables.
- Added locked scout/confirmation candidate generation.
- Added persistent claim IDs, evidence receipts, checks, and run imports.
- Added explicit supersession chains and history reconstruction.
- Added AND-within-derivation / OR-between-derivations dependency behavior.
- Added forward collapse analysis and non-destructive re-examination queue.
- Added direct evidence, derivation, contradiction, supersession, and revocation APIs.
- Added immutable plan revisions from browser or API.
- Added local browser interface and Windows launch scripts.
- Added Markdown, HTML, and JSON research dossiers.
- Configured SQLite for the single-process local FastAPI service.
